# Student Placement Prediction

## Overview
This project predicts whether a student is likely to be placed using Machine Learning.

## Features
- Student placement prediction
- Streamlit web application
- Random Forest Classifier
- Prediction confidence
- User-friendly interface

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Dataset Features
- CGPA
- Internships
- Projects
- Workshops/Certifications
- Aptitude Test Score
- Soft Skills Rating
- Extracurricular Activities
- Placement Training
- SSC Marks
- HSC Marks

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
